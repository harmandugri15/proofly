# Antigravity Design Expert Skill

This skill guides the design and transformation of web applications into captivating, modern, aesthetic experiences tailored for the next generation of builders, developers, and recruiters.

## Core Design Principles

### 1. Aesthetic DNA: Modern Social Meets High-Trust Evidence
- **Social Feed & Community Vibe**: Draw inspiration from modern Instagram cards, Reddit discussion threads, and GitHub developer profiles—combining clean content cards, interactive engagement badges, story-style avatar borders, and tag pills.
- **Glassmorphism & Depth**: Rich obsidian/midnight backgrounds (`#08090e`, `#0d0f17`) layered with frosted translucent cards (`backdrop-blur-xl bg-slate-900/60 border border-white/5 hover:border-white/15`).
- **Hyper Accents**: Vibrant gradients and neon highlights (electric violet, emerald green, cyber cyan, coral pink, sunset amber) for badges, metrics, and call-to-actions.
- **Micro-Interactions**: Hover lifts, subtle border glows, active pill tabs, animated verified rings, and smooth transitions.

### 2. Typography & Hierarchy
- Bold, expressive headings paired with ultra-clean readable body copy and monospace accents for verified hashes, commit counts, and handles.
- High-contrast text labels: white headings (`text-white font-extrabold`), subtle silver subtitles (`text-slate-300`), muted slate metadata (`text-slate-500 font-mono text-xs`).

### 3. Component Architecture
- **Navbar**: Floating pill navigation with blur effect, active gradient glows, and quick-access indicators.
- **Hero & Headers**: Engaging banners with gradient meshes, live badge chips, and bold copy.
- **Evidence & Project Cards**: Social card layout with verified trust ribbons, live tags, star/fork counters, and 1-click preview triggers.
- **Feed & Writeups**: Reddit/Substack hybrid cards with upvote aesthetics, read-time chips, and tech tags.
- **Integrations Strip**: Vibrant platform tiles (GitHub, LinkedIn, LeetCode, Codeforces) with live status dots.
